# Macrosona

Retrieve, capture and distil knowledge across Chat, Work/Cowork and Coding through the existing hosted OAuth connection.

- **Retrieve** (`macrosona-retrieve`): recall knowledge with evidence and attribution.
- **Capture** (`macrosona-capture`): save concise notes explicitly requested by the user. For an accepted queued receipt: “Queued for ingestion.”
- **Distil** (`macrosona-distil`): use the client's file tools to create a linked wiki and standalone offline knowledge skill from selected memories. Search-based coverage is best-effort; the recipient package needs no Macrosona connection.

Run `macrosona-setup` to connect or repair access. Its [setup guide](skills/macrosona-setup/references/SETUP.md) covers installation and verification per interface. `macrosona-memory` remains the compatibility entry point. Creating files depends on host capabilities; local installation alone does not establish Chat or Work access. These packages do not automatically capture conversations or distribute files.
