# Macrosona

Use Macrosona as long-term memory for Chat, Work/Cowork and Coding. This plugin bundles memory and setup skills with a hosted OAuth MCP connection for read-only retrieval and explicitly approved notes.

Run `macrosona-setup` after installation. Its [setup guide](skills/macrosona-setup/references/SETUP.md) covers account-level installation, OAuth and verification in each interface. Installing a local coding plugin alone does not establish account access in Chat or Work.

Use `macrosona-memory` for retrieval, approved captures and processing-delay guidance. A queued capture confirms delivery; it may not be searchable until ingestion and processing complete. These OAuth packages do not automatically capture conversations.
